# Images

The game runs without any image files: the main leaf is drawn in code and the buildings use emoji
icons. To use real Indiana State University logos, places and people:

1. Put the image files in this folder or in `images/buildings/`. Any browser image format works
   (`.png`, `.jpg`, `.webp`, `.svg`). Square images look best; a transparent PNG works best for the leaf.
2. Open `images/images.js` and set the matching entry to the file's path, for example:

   ```js
   sam: 'images/buildings/sam.jpg',
   ```

3. Reload the game. The picture replaces the emoji in the store and on the campus view.

| Key | Used for | Suggested picture |
| --- | --- | --- |
| `leaf` | The big clickable leaf | ISU sycamore leaf logo |
| `sapling` | Sycamore Sapling | A young sycamore tree on campus |
| `sam` | Sycamore Sam | The mascot |
| `bluecrew` | Blue Crew | Student section at a game |
| `fountain` | The Fountain | The fountain on campus |
| `normalhall` | Normal Hall | Normal Hall |
| `library` | Cunningham Library | Cunningham Memorial Library |
| `stadium` | Memorial Stadium | Memorial Stadium |
| `hulman` | Hulman Center | Hulman Center |
| `bird` | Larry Bird Statue | The Larry Bird statue |
| `parade` | Homecoming Parade | Homecoming parade |
| `wabash` | Banks of the Wabash | The Wabash River |
| `alumni` | Sycamore Alumni Network | Commencement or alumni event |
